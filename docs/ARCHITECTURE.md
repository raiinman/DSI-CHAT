# Architecture

A platform-independent FeatureRuntime owns enabled feature cleanup and failure reporting. Features declare an id, label and start function returning a cleanup function. Reconciliation is synchronous and supports reversible browser display changes.

The Chromium adapter uses a statically declared isolated-world content script on https://discord.com/channels/* only. It installs style elements; it does not hook Discord's private JavaScript runtime. The extension popup writes a single namespaced local settings record. The content adapter listens for changes and reconciles enabled features. Safe mode runs no features.

The build concatenates the original plain-JavaScript modules into one content script and copies the popup and manifest. There is no package dependency, remote code, telemetry or upstream updater.

Mobile and desktop adapters are not implemented. A shared lifecycle does not make DOM features executable in Android.

The GitHub Pages preview reuses the actual feature runtime and CSS against sample messages. Preview settings use a separate browser localStorage record. Pages hosts a ZIP built from the same original extension sources; no GitHub login is needed to download it. The deployment workflow builds and verifies before publishing.

The messenger preview keeps contact data and per-conversation histories in a small original model. Messages stay in tab memory, and rendering uses textContent for message bodies. No network adapter is connected. The Trillian-inspired layout belongs to the preview; applying that shell to Discord remains separate platform work.

The preview's theme selector is independent of feature lifecycle. Its complete CSS themes cover the entire messenger and preferences. It shares Compact messages and Reduced motion with the extension, but does not install Discord's Signal CSS, which would override light surfaces. The preview settings record stores a validated theme alongside normalized feature settings; older Signal selections migrate to High contrast. Discord/Relay/Local buttons display preview-only connection status and make no network requests.

The rebuilt preview owns a saved signal Play/Pause setting and explicit system-motion override. By default, reduced-motion preferences stop the decorative equalizers. Clicking Play clears the preview Reduced motion feature choice and opts the equalizers into motion under a system preference only when that preference is currently active. Other page animations still obey the system setting. Meter height/animation is CSS only, not audio input, network health or real connection activity.

The workspace-tools module owns four native modal surfaces: a searchable archive of the active in-tab conversation, a contact card, local profile editing and a cursor-aware emoji picker. All user/message text is rendered with textContent. Conversation export generates a local text Blob; it performs no upload. Profile name/note use the separate validated localStorage record dsiChat.localProfile.v1. A renamed profile changes future message authors; historical authors remain unchanged. This is local display personalization, not an account or authentication system. Native modal dismissal returns focus to the opener, or to the composer after an explicit compose/emoji action. On desktop displays at least 1000px wide and 640px high, window height follows the viewport, and contact/message areas scroll internally.

Contact organization uses the validated dsiChat.contactBook.v1 localStorage record, separate from appearance and profile. contact-book.mjs owns local group names, membership and favorites; contact-tools.mjs renders the list and native action/group dialogs. Search matches names, status notes and local group names, including collapsed groups. Favorites filter the existing list without duplicating contacts. Custom group removal reassigns members to the first default group and retains favorites; messages, tabs and drafts are untouched. Two default groups can be renamed but not removed. Storage failure leaves changes usable for the visit and reports the limit through a status region. Contact actions return focus to their row, or to search if filtering removes it. Write a message returns focus to the composer. Group collapse is session-only; transient search/favorite filters reset on reload.
