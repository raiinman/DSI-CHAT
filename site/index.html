03 / GET ON AIR

Install the browser prototype.

  1. Download and extract. Use the extension download button above. Extract the ZIP into a folder.
  2. Load the extension. Open chrome://extensions or edge://extensions, turn on Developer mode, then choose Load unpacked and select the extracted folder.
  3. Open Discord web. Refresh an existing Discord tab. Open the DSI CHAT extension popup and choose your features.

Desktop browsers only. Android and the installed Discord desktop app are still in development. The extension has passed automated build checks; live Discord acceptance testing remains pending.
