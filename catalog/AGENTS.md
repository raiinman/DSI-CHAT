# Generated feature catalog

## Purpose
Provide a machine-readable list of implemented original browser/Windows plugins; native descriptors live in android/plugins.json.

## Ownership
features.json is generated by scripts/catalog.mjs from src/plugins/builtins.mjs.

## Local Contracts
List implemented capabilities and actual platform support only. Features are disabled by default. Do not claim upstream plugin-suite parity or unsupported platforms.

## Work Guidance
Edit source declarations, then regenerate; do not manually edit features.json.

## Verification
npm run catalog regenerates the file. Existing CI requires git diff --exit-code catalog/features.json after generation.

None.
